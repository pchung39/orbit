Opening a case saves a window of telemetry for investigation. The procedure for that alarm stays on the case.

What a saved snapshot preserves

A saved snapshot retains the telemetry window captured for a case. Refreshing the dataset catalog does not replace that saved evidence.

Data maintenance

Manual catalog actions. They do not rewrite sealed snapshots, case reports, or recorded assessments.
